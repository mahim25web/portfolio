About me

I started in digital design, branding and visual marketing, and that background still shapes how I build: I care how a page looks, how it reads and how it feels to use. That curiosity pulled me into code, and now I turn those designs into real, working websites.

My programming journey began with HTML, CSS and JavaScript, then grew into React, Next.js, Firebase, Supabase and Node.js. Along the way I’ve built web apps, a student portal, a private chat app and a small game in Python.

I enjoy front-end work most: interfaces with careful layout, motion that explains what changed, and tidy code I can come back to months later. I also like AI features that make a product more useful.

Outside of code I like creative, visual experiments: animated web pages, hand-tracking visuals built with MediaPipe, and exploring ethical hacking and Android security on my own devices.

I’m calm, curious and a bit of a perfectionist. I like to ship something small, show it to people, and improve it.
